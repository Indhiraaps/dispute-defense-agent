Architecture · free stack · PayPal sandbox

Dispute Defense Agent

An agent that reads a PayPal buyer dispute, gathers the seller's real records, scores the case with fixed rules, and drafts a cited evidence packet. It only submits to PayPal after the seller approves. Every part of the stack below is free.

How a dispute moves through the agent

From the moment a buyer opens a dispute to the final outcome. The colour of each number shows who does that step.

  1. 1

    Detect

    Code

    PayPal sends CUSTOMER.DISPUTE.CREATED. The app checks the signature is genuine and starts the deadline countdown. A scheduled poll catches any missed webhook.

    PayPal WebhooksNext.js API route
  2. 2

    Understand

    CodeAI

    Fetch the dispute and map PayPal's reason code to a claim type: item not received, not as described, or unauthorized. The LLM writes a one-line summary of the buyer's complaint.

    Disputes APIGemini (free tier)
  3. 3

    Gather evidence

    AI agent

    The agent picks which tools to call for this claim type (payment, order, tracking, messages, photos) and keeps going until it has enough. It finds admissions in messages such as "got it, thanks", and compares buyer photos with listing photos. Each record is saved with an ID like TRK-001 or MSG-003.

    Vercel AI SDKPayPal Agent ToolkitTransaction SearchShipment TrackingOrders v2Gemini visionSQLite
  4. 4

    Score the case

    Rules

    Fixed points, for example tracking matches +30 and carrier shows delivered +30. A score of 70 or more means contest, 40 to 69 means offer a partial refund, and under 40 means accept. The breakdown is shown to the seller.

    TypeScript function
  5. 5

    Draft the response

    AI

    An explanation of at most 150 words where every sentence cites an evidence ID. For an offer, it suggests a refund amount within limits the rules set.

    Gemini structured outputzod schema
  6. 6

    Check citations

    Code

    Every cited ID must exist, and numbers, dates and tracking IDs must match the records exactly. A sentence that fails is removed or sent back.

    Fails → back to step 5, at most 2 retries

    zodTypeScript
  7. 7

    Build the PDF

    Code

    Cover summary, tracking proof, listing snapshot and message excerpts in one evidence file.

    pdf-lib
  8. 8

    Seller approves

    Human

    One screen with the countdown, score breakdown and draft, where each citation opens its source. The seller chooses Approve and submit, Edit, or Handle it myself. Nothing goes to PayPal without this click.

    Next.jsAG Grid Community
  9. 9

    Submit to PayPal

    Code

    Contest with provide-evidence, offer with make-offer, or concede with accept-claim. Every request carries a unique PayPal-Request-Id, so a retry never submits twice.

    Disputes APIcustom dispute tools
  10. 10

    Track the outcome

    Code

    Listen for CUSTOMER.DISPUTE.UPDATED and CUSTOMER.DISPUTE.RESOLVED, log won, lost or settled, and update the playbook of which evidence wins.

    PayPal WebhooksSQLite

Free-tier catches

Claude API isn't free

It has no free tier, so Gemini is the main model and Ollama is the backup.

Gemini free-tier data

Google may use free-tier prompts to improve its products. Use sandbox data only and mask buyer emails and addresses before prompting.

Rate limits

One dispute needs about 4–6 LLM calls, which is fine for a demo. Check current limits in AI Studio, because free tiers change.

Render sleeps

The free service sleeps when idle and takes about a minute to wake. Open it a few minutes before presenting. Its disk resets, so reload demo data on start.

Ollama on a laptop

Vision models need plenty of RAM or GPU memory and run slower. Test one full dispute end to end before relying on it.

Test these three first

The demo depends on them, and none is confirmed yet. If any fails, change the plan before building the rest.

  1. The exact request format for provide-evidence (file part names and allowed evidence types).
  2. Creating a test dispute in the sandbox: make a sandbox payment, then open a dispute as the sandbox buyer.
  3. Calling the sandbox-only adjudicate endpoint so the dispute resolves live on stage.
